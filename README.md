## 阅读边界

“低性价比”描述的是某些选择中的可避免代价，不衡量一个人的价值。书中反向秘诀是娱乐化表达，不能当作应当照做的行动建议；每条的分析、证据边界与最小止损应一起阅读。

四个部末案例均为虚构，研究结论也有各自的样本、地区和适用范围。本书不替代医疗、法律或财务专业意见。
